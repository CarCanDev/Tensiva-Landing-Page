# Directorio de Capturas de la Plataforma CORDIA

Coloca aquí los archivos de imagen (.png) con los siguientes nombres:

1. `dashboard.png`           -> Consola Central / Vista General del Operador (Sección 4: CordiaIntro)
2. `tension.png`             -> Monitoreo de Tensión Continua (Función 01)
3. `caidas.png`              -> Detección Automática de Caídas (Función 02)
4. `cambios-tension.png`     -> Detección de Cambios de Tensión (Función 03)
5. `videomonitoreo.png`      -> Videomonitoreo Integrado y Cámaras (Función 04)
6. `consola-unificada.png`   -> Consulta Integrada Multisensor (Función 05)
7. `evaluacion.png`          -> Evaluación y Auditoría de Eventos (Función 06)
8. `revision-operador.png`   -> Panel de Despacho y Respuesta del Operador (Sección 6: Cómo Funciona)

En cuanto guardes los archivos en esta carpeta con esos nombres exactos, la aplicación web los detectará y los mostrará automáticamente dentro de sus marcos interactivos.
